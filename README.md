# ✨ SunDown Studio Website Clone by N

A visually stunning and fully responsive clone of the [SunDown Studio Website](https://sundown-studio.com/) built using HTML, CSS, and JavaScript. This project showcases smooth scroll-based animations and creative layouts inspired by the original site. Perfectly crafted for animation studios and creative portfolios.

---

## 🔥 Features

- 🎨 Pixel-perfect UI and layout inspired by the official Sundown Studio.
- 📱 Fully responsive design for all devices.
- 🎬 Scroll-triggered animations using GSAP for a dynamic user experience.
- 🖼️ Smooth section transitions, hover effects, and text reveals.
- 🧠 Clean and modular code using HTML, CSS & Vanilla JavaScript.

---

## 🛠️ Tech Stack

- 🧱 HTML  
- 🎨 CSS  
- 🧠 JavaScript (Vanilla JS)  
- ⚡ GSAP (GreenSock Animation Platform)
